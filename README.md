# Deskripsi Program
PURRMART adalah sistem manajemen toko sederhana berbasis Command-Line Interface (CLI) yang memungkinkan pengguna untuk mengelola daftar barang dan pengguna, melakukan proses login/logout, registrasi pengguna baru, serta membaca data dari file konfigurasi eksternal. Di dalam program ini juga terdapat fitur fitur tambahan seperti permainan permainan. Program ini dirancang menggunakan pendekatan modular dengan implementasi ADT (Abstract Data Type) untuk mempermudah manipulasi data.
